# 🐱 Kitty Ipsum Translator

This project is part of the **freeCodeCamp - Relational Databases Certification** course. 
I built a professional Bash script that automates text processing and translation.

## 🚀 Key Features
* **Bash Scripting**: Automated complex tasks using `translate.sh`.
* **Data Transformation**: Used `sed` with global flags to replace patterns across entire files.
* **Piping & Redirection**: Mastered the flow of data using `|`, `<`, and `>`.
* **Grep & Regex**: Filtered and searched specific data patterns effectively.

## 🛠 Tools Used
* Bash (Linux Terminal)
* Sed (Stream Editor)
* Git & GitHub
